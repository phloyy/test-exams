# Подготовка к тестам — Интерактивное приложение

Интерактивное приложение для подготовки к экзаменам по нескольким предметам.

## Возможности

- **Выбор предмета**: Менеджмент, Экономика (встроены) и любые свои импортированные тесты
- **Варианты**: вопросы каждого предмета разбиты на варианты по 30 вопросов
- **Режим тренировки**: Мгновенная проверка с детальными пояснениями
- **Режим экзамена**: Результаты и разбор в конце теста
- **Импорт JSON**: загрузка собственных тестов прямо на сайте (сохраняются в браузере)
- **Прогресс**: автосохранение по каждому варианту в localStorage

## Импорт своего теста

На экране выбора предмета нажмите «Выбрать JSON-файл». Ожидаемый формат — массив объектов:

```json
[
  {
    "question": "Текст вопроса",
    "options": [
      { "text": "Вариант 1", "isCorrect": false },
      { "text": "Вариант 2", "isCorrect": true }
    ],
    "explanation": "Пояснение к правильному ответу"
  }
]
```

Также поддерживается внутренний формат (`answers`/`correct` и `explanation` как объект).
